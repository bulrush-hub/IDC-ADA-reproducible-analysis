# IDC TabPFN-3 建模比较工作日志

日期：2026-08-02

本日志记录 TabPFN 比较流程的每一步、关键判断、复现条件和当前阻塞点。现有随机森林结果不被覆盖；TabPFN 使用独立环境和新的输出文件。

## 步骤 1：确认最新版与适用范围

- 通过 Prior Labs 官方 GitHub Releases 与 PyPI 核对，当前稳定版为 `tabpfn 8.2.0`（2026-07-28 发布）。
- `tabpfn 8.2.0` 的默认权重为 TabPFN-3；代码中不回退到 TabPFN-2.x。
- 官方说明：TabPFN-3 在 CPU 上允许最多 5,000 个样本；本次开发集 2,237 行、测试集 374 行，处于允许范围内。
- 官方建议直接传入原始数值/类别字段，不做标准化或 one-hot。为遵循模型设计，TabPFN 使用原生类别索引；输入信息仍与当前模型完全相同。
- 权重适用 `TabPFN-3 Non-Commercial License v1.0`。非商业许可需由使用者本人接受，商业或生产用途需要另行授权。

官方来源：

- https://pypi.org/project/tabpfn/
- https://github.com/PriorLabs/TabPFN/releases/tag/v8.2.0
- https://docs.priorlabs.ai/how-to-access-gated-models
- https://huggingface.co/Prior-Labs/tabpfn_3/blob/main/LICENSE

关键点：软件包版本与模型权重版本是两个概念。本次固定 `tabpfn==8.2.0`，并使用该版本默认的 TabPFN-3 权重。

## 步骤 2：建立项目内隔离环境

- 新建项目本地环境 `.venv-tabpfn`，保留原基线环境 `.venv` 不变。
- 安装位置全部位于项目目录；没有向系统 Python 或全局 site-packages 安装任何包。
- 固定顶层依赖于 `requirements-tabpfn.txt`，完整解析版本保存于 `requirements-tabpfn.lock.txt`。
- 当前关键版本：Python 3.12.13、TabPFN 8.2.0、PyTorch 2.13.0、pandas 3.0.5、scikit-learn 1.9.0。
- 自动安装得到 CPU 版 PyTorch (`torch 2.13.0+cpu`)；系统 NVIDIA GPU 未被此环境调用。
- Windows 首次安装 PyTorch 时出现长路径错误。使用临时 `Z:` 盘符映射同一项目目录后完成安装；虚拟环境仍实际保存在项目的 `.venv-tabpfn`。

关键点：分离环境可避免 TabPFN/PyTorch 依赖改变既有随机森林结果，也方便 Linux 迁移时分别重建两个环境。

## 步骤 3：固定公平比较设计

- 数据源：`outputs/IDC_modeling_table_final_model_ready.xlsx` 的 `Modeling_Data`。
- 不重新生成拆分；直接复用 `work/modeling_artifacts/split_audit.csv`。
- 行数核验：train 1,864；validation 373；test 374；合计 2,611。
- 开发集为 train+validation，共 2,237 行；测试集在模型开发阶段保持封存。
- 复用同一 29 个主分析特征：16 个类别特征、7 个连续派生特征、6 个二元/缺失指示特征。
- 不加入 `molecule_inn_name`、研究 ID、来源 ID 或结局派生字段，防止药物身份记忆和信息泄漏。
- 开发集内部使用 5 折 `GroupKFold`，分组键仍为 `model_split_group`。
- 连续结局：`ada_frequency_percent`；主要比较 MAE、RMSE、R²。
- 二分类结局：`ada_high_10`；比较 ROC-AUC、PR-AUC、F1、平衡准确率、Brier、Log Loss。
- 最终比较读取当前已选随机森林的原始测试指标，不重新调参或重选基线模型。

关键点：比较改变的只有模型及其模型适配预处理；样本、特征信息、拆分和评价指标保持一致。
