# IDC 建模下一阶段：文献依据与执行大纲

日期：2026-08-02

## 一、当前结论与边界

- 当前随机森林与 TabPFN-3 已在同一 29 项特征、同一研究组拆分和同一 374 行测试集上比较。
- TabPFN-3 在连续 ADA 频率预测以及二分类概率校准方面更好；固定 0.5 阈值下的 F1 与平衡准确率没有改善。
- 现有拆分按 `model_split_group`（研究/试验）隔离，但这不自动等同于“全新分子”隔离；同一分子可能出现在不同研究和不同分区。
- 测试集结果已经被查看。此后不再使用该测试集选择模型、阈值、校准方法、特征或亚组规则；所有新增选择只允许在开发集完成。
- IDC 行是研究/治疗臂层面的汇总记录，不是患者级数据。因此当前主要 estimand 是“给定研究、产品和检测条件时的研究层面 ADA 发生率”，不能直接解释为患者个体风险。

## 二、文献与监管依据

1. **TRIPOD+AI（BMJ 2024）**：模型评估不应只报告区分度，还应报告校准图、校准斜率以及在明确使用场景下的临床效用；应清楚区分训练、调参与独立评价数据。
   - https://www.bmj.com/content/385/bmj-2023-078378
2. **PROBAST+AI（BMJ 2025）**：需要从参与者/数据来源、预测变量、结局和分析四个方面评价偏倚风险与适用性，特别关注过拟合、数据泄漏、不恰当验证和缺失数据处理。
   - https://www.bmj.com/content/388/bmj-2024-082505
3. **临床预测模型开发与外部验证指南（BMJ 2024）**：二分类模型应同时检查校准截距、校准斜率和柔性校准曲线；外部验证必须使用独立数据并给出不确定性。
   - https://www.bmj.com/content/386/bmj-2023-078276
   - https://www.bmj.com/content/384/bmj-2023-074820
4. **嵌套交叉验证（Varma & Simon, 2006）**：当交叉验证同时承担模型/阈值选择和性能估计时，普通 CV 会产生乐观偏倚；应把选择限制在内层，外层只做评价。
   - https://pubmed.ncbi.nlm.nih.gov/16504092/
5. **决策曲线分析（Vickers 等）**：只有在阈值对应明确行动且能解释假阳性/假阴性代价时，净获益才有临床意义；不能仅因存在 10% 标签就自动宣称临床效用。
   - https://www.bmj.com/content/352/bmj.i6
6. **外部验证样本量（Riley 等, 2021）**：外部验证样本量应围绕校准、区分度和净获益的期望置信区间精度设计，不能只套用固定事件数规则。
   - https://pubmed.ncbi.nlm.nih.gov/34031906/
7. **TabPFN（Nature 2025）**：TabPFN 面向中小型表格数据具有较强预测能力，但具体数据库仍必须通过与领域基线相同的数据划分进行独立验证。
   - https://www.nature.com/articles/s41586-024-08328-6
8. **FDA ADA assay guidance（2019）与 EMA immunogenicity guideline**：ADA 发生率受检测灵敏度、drug tolerance、采样时点、疾病、免疫调节合并用药、剂量方案等影响。跨研究模型必须把这些因素视为测量和可迁移性问题，而不仅是一般协变量。
   - https://www.fda.gov/regulatory-information/search-fda-guidance-documents/immunogenicity-testing-therapeutic-protein-products-developing-and-validating-assays-anti-drug
   - https://www.ema.europa.eu/en/documents/scientific-guideline/guideline-immunogenicity-assessment-biotechnology-derived-therapeutic-proteins-first-version_en.pdf

## 三、执行大纲

### 阶段 A：锁定问题定义与验证协议

1. 把当前主要用途定义为研究层面 ADA 发生率预测；二分类 `ADA ≥10%` 暂作为统计分层标签，不直接称为临床高风险阈值。
2. 锁定现有测试集；新增分析只使用 train+validation 开发集。
3. 固定 29 项特征、缺失处理、模型版本、随机种子与研究组定义。
4. 建立数据字典，标记预测时可获得字段、测量方法字段和潜在泄漏字段。

### 阶段 B：开发集 OOF 校准与阈值分析

1. 使用 5 折 `GroupKFold(model_split_group)` 为随机森林和 TabPFN-3 生成逐行 OOF 预测。
2. 二分类报告 ROC-AUC、PR-AUC、Brier、Log Loss、校准截距、校准斜率、柔性/分箱校准图。
3. 连续结局报告 MAE、RMSE、R²、均值偏差、Spearman 相关、按实际 ADA 区间的误差以及预测区间覆盖准备情况。
4. 绘制 0.05–0.80 阈值敏感性表；只有在明确行动成本后才选择阈值。探索性 F1/平衡准确率最优阈值不得用作独立测试结论。
5. 若需概率再校准，校准器必须在内层训练数据拟合，再由外层折评价；不能对测试集后处理。

### 阶段 C：泛化与稳健性

1. 开发集内按 `molecule_inn_name` 分组交叉验证，评价对全新分子的外推。
2. 检查同一分子是否跨原 train/validation/test；将“新研究预测”和“新分子预测”明确作为两个不同任务。
3. 按 assay platform、assay sensitivity 是否报告、评估时长、疾病类别、给药途径、样本量、biosimilar 状态分层报告误差与置信区间。
4. 比较未加权研究层面指标与按 `n_ada_assessed` 加权指标；两者回答不同问题，不能混用。
5. 对 count-frequency mismatch、依赖记录和缺失检测信息继续做敏感性分析。

### 阶段 D：外部验证与报告

1. 优先获取按时间或数据来源真正独立的新研究；在收集前锁定模型与分析计划。
2. 根据预期事件比例、预测分布以及校准斜率/ROC-AUC/净获益的目标精度计算外部验证样本量。
3. 外部验证同时报告整体和预设亚组性能，不在外部集重新选特征或模型。
4. 形成 TRIPOD+AI 报告清单、PROBAST+AI 自审表、模型卡和非商业许可说明。

## 四、优先级与完成判据

| 优先级 | 工作 | 完成判据 |
|---|---|---|
| P0 | 测试集锁定与 estimand | 文档明确研究层面用途；新增脚本不读取测试结局用于选择 |
| P0 | 开发集 OOF 预测 | 两模型每行恰有一条 OOF 预测；训练折和验证折研究组零重叠 |
| P0 | 校准分析 | 截距、斜率、校准图、Brier、Log Loss 和 Bootstrap CI 齐全 |
| P1 | 新分子验证 | molecule 分组零重叠；单列报告，不与新研究任务混淆 |
| P1 | ADA 测量稳健性 | 预设 assay/采样/样本量亚组有样本数、事件数与区间估计 |
| P1 | 外部验证设计 | 明确数据源、时间切点、样本量精度目标和锁模日期 |
| P2 | 临床效用 | 只有获得可解释行动阈值及代价权重后才正式做决策曲线 |

## 五、当前阶段的模型决策规则

- 不立即淘汰随机森林；它是透明、稳定且计算成本较低的基准。
- TabPFN-3 作为连续 ADA 预测的领先候选，并作为二分类概率模型的领先候选。
- 最终模型选择以开发集外层分组验证、全新分子验证和未来外部验证的综合结果为准，而不是只看当前 374 行测试集。
- 特征重要性只用于预测解释和数据质量排查，不用于因果声称或自动删特征。
