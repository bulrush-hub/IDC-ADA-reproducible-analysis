# 数据说明与统计单位

## 三条独立数据分支

1. **主建模分支**：从已清洗、人工审核的研究/治疗臂表出发，共 2,611 行，用于随机森林、TabPFN 和 OOF 验证。
2. **论文复现分支**：从公开 IDC V1 all-tables 的 3,334 条临床试验行出发，筛到 2,666 条暴露且有 ADA frequency 的候选记录；八个代理字段完整时为 1,443 行。
3. **去重敏感性分支**：在 2,666 条候选记录上生成 110 行和 146 行的两个代表记录表，并分别形成 66 和 78 个完整代理 GLM 案例。

这些数字不能互换。特别是：

- `110` 是清洗后唯一分子数，不是完整 GLM 样本量；
- `66` 是 110 个分子中八项代理字段都完整的分子数；
- `146` 是分子-疾病组合数，不是独立分子数；
- `1,443` 是公开代理设计矩阵的完整案例，不是论文作者的精确分析集。

## 独立性

- IDC 行是研究/治疗臂汇总，不是患者级记录。
- 同一分子可出现在多个研究、疾病、剂量和时间点中。
- 研究泛化用 `model_split_group` 分组；全新分子泛化用标准化分子名分组。
- row-weighted 和 molecule-balanced 指标回答不同问题，必须同时标注权重口径。

## 缺失值

- `_note`、审核说明和 correction flag 的空值通常代表“没有问题”，不得画入普通缺失率排行。
- 结构性不适用、真实未测量、无法解析和人工未审核应分别编码。
- 完整案例分析不会从清洗表删除不完整分子，只是在特定模型拟合时排除。
